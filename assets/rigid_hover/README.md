# 单段刚性吊挂

`drone_payload.urdf` 的无人机本体、桨叶、质量及电机参数派生自固定版本 `Flare/assets/suspended_system/real_sus_exp.urdf`；可视网格继续引用该子模块，未改写上游模型。

删除原柔性绳全部中间段与负载端转动关节。仅保留一根 0.48 m 刚性杆，杆质量 0.005 kg；负载 0.068 kg 在末端固定。无人机本体 0.3 kg。自由转动集中在无人机质心处：三个同位置的连续 XYZ 转动关节模拟球铰，两个中间虚拟铰链各有 1e-5 kg 质量和 1e-8 kg m² 惯量，以避免零惯性奇异。它是 Euler 关节的球铰近似，姿态存在坐标奇异性；任务在大摆角前终止。

没有绳子弯曲、伸长、松弛或负载端自由关节。杆可承受拉力和压力，因此不是柔性绳模型。当前关闭碰撞，由环境高度/边界条件终止。物理参数修改时需要同步 URDF 与 configs/rigid_hover.yaml；入口会检查杆长和主要质量是否一致。
